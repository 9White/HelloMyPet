# HelloMyPet
一个桌宠应用，支持互动

## 在其他电脑运行

1. 安装 Python 3.10+（Windows）
2. 克隆或下载本仓库到任意目录
3. 安装依赖：
   ```
   pip install -r requirements.txt
   ```
4. 启动：
   ```
   python main.py
   ```

- 素材（动画帧、图标）与代码均按工程目录相对定位，拉到任意路径都可运行
- 开机自启动、开始菜单快捷方式在托盘菜单里操作（各自电脑独立设置）
- 动画帧率 24fps，透明置顶浮窗；若屏幕缩放比例较大，字体显示异常可调整系统 DPI 设置
